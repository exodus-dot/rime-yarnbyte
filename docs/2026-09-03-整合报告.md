# rime-yarnbyte 整合报告（2026-09-03，第二版）

`rime-yarnbyte` = 手工复制的 `rime-crane` 完整副本（含 `build/`、git 历史）+ 由 `InputData\integrate-yarnbyte.ps1`
装入的 `rime-fast-xhup` 飞鹤快拼 / 飞鹤快码 / Easy English 及其全部依赖。
`rime-crane` 与 `rime-fast-xhup` 两个源目录未做任何改动，可随时用 `switch-rime-currentdir.bat` 切回。

脚本可重复执行：上游 fast-xhup 更新后，重新运行一次即可把 fast 部分刷新，crane 文件不会被碰。

## 4. 为什么需要 `flypy_preset.yaml`

fast-xhup 的三个方案写着 `key_binder: import_preset: default`。整合版里 default.yaml 是 crane 的，其 key_binder 带
`- = 翻页` 等绑定，而飞鹤快拼把 `-`、`=` 用作计算器 / 英文造词编码，会被翻页截走。
因此把 fast-xhup 自带 default.yaml 的 key_binder / recognizer / punctuator 三节原样搬到 `flypy_preset.yaml`，
三个 fast 方案通过 custom 补丁改为从它继承；crane 方案继续继承 default.yaml。

## 5. 校验结果

- 脚本内置校验 + Python 静态校验均通过：96 个 yaml 语法正常；schema_id 无重复；所有 dictionary / import_tables / Lua 模块 / require / OpenCC json 及 txt / import_preset / __include 引用均存在
- 已加载配置中无 `alternative_select_labels`，fast 方案无任何 `style` 覆盖；`weasel.yaml`、`default.yaml` 与 crane 逐字节相同
- 部署时编译的方案：xhup、double_pinyin_flypy、flypy_xhfast、flyhe_fast、easy_en + 依赖 xhup_reverse、melt_eng、radical_pinyin、ecdict、flypy_radical、flypy_reverse

## 6. 已知事项

1. `zh-hans-t-essay-bgw.gram` 语法模型两边都没有，飞鹤快拼会在日志里报找不到但不影响使用；要用可按 fast-xhup README 链接下载放到根目录。
2. 飞鹤快拼 / 快码启用了 `predictor`（联想预测），依赖小狼毫自带的 librime-predict 插件；fast-xhup 原目录在同一台机器能部署，说明可用。
3. 全局行为以 crane 为准：Shift_L「上屏编码并切英文」，CapsLock「清空并切英文」，选单热键 F4 / Ctrl+`。
4. 首次部署要编译 flypy_base（25 MB）、ecdict（28 MB）等大词库，通常 2~5 分钟；期间候选栏可能暂时用小狼毫默认外观，等托盘弹出「部署完成」再看。
5. 本机（VMware）没有小狼毫，无法实际部署；以上为静态校验结果。
